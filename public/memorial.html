MORE · SAVING & PRIVACY

Your plan. Your choice.

Saving is off until you explicitly choose it. Temporary edits are lost when this page closes or reloads. A browser may warn before leaving, but mobile browsers do not reliably show that warning.

Local browser saving

Optional autosave stays in this browser profile and origin, unencrypted. Anyone using the profile may access it. It is separate from photo-album saving and does not transfer to another device.

Older workspaces & browser storage

This version saves separately from the older memorial-only workspace. Restore reads the older copy only if no new copy exists. It never restores automatically. Browser storage can be cleared and is not an archival backup.

Delete a saved copy

This only removes this version’s browser-saved planning data. Current page edits, older saved copies, photo albums and downloads are not erased.

MORE · APP & OFFLINE

Keep your workspace close.

Use this as a normal webpage or add it as a browser app where supported.

Optional app setup

Checking this browser’s app support…

If your browser offers it, use Install app or Add to Home Screen. Available options depend on your browser and device.

What offline setup does—and does not do

Only this app’s static interface is cached. Portraits, tasks, quotes, photo rooms and API responses are not cached by this setup. Edits still disappear on reload unless you enable planning-data saving separately.

It does not install the Node photo-room server, turn a phone into a host, or create a permanent guest link. Browser cache is not a backup. Saved work is restored explicitly; installed-app storage may differ. Save or back up before closing or updating.
